# 书海拾贝 - 二手书交易平台

> 让知识流动起来 📚

## 项目简介

书海拾贝是一个面向校园的二手书交易平台，采用**面交模式**，让买卖双方线下见面完成交易，安全放心。

## 核心功能

### 📖 书籍管理
- 发布二手书：支持ISBN自动查询书籍信息
- 书籍搜索：按书名、作者、ISBN搜索
- 书籍详情：查看完整信息和面交地点

### 🛒 交易流程
- 购物车：添加心仪书籍，统一结算
- 订单管理：查看订单状态和详情
- 面交模式：线下见面完成交易

### 📍 面交流程
```
待确认 → 已确认 → 面交中 → 已完成
   ↓        ↓        ↓
  取消     取消      取消
```

### ⭐ 评价系统
- 交易完成后可评价（1-5星）
- 查看书籍和卖家评价

## 技术栈

### 后端
- Java 21 + Spring Boot 3.3
- Maven 构建

### 前端
- React 18 + Vite
- React Router 6
- 响应式设计

## 快速开始

### 环境要求
- JDK 21+
- Node.js 18+
- Maven 3.8+

### 后端启动
```bash
cd Java
mvn spring-boot:run
```
后端运行在 `http://localhost:8081`

### 前端启动
```bash
cd Html
npm install
npm run dev
```
前端运行在 `http://localhost:5173`

## API 接口

详见 [API文档](docs/api.md)

### 主要接口
| 模块 | 路径 | 说明 |
|------|------|------|
| 认证 | `/api/auth/*` | 注册、登录、刷新Token |
| 书籍 | `/api/books/*` | 书籍CRUD、搜索、ISBN查询 |
| 购物车 | `/api/cart/*` | 购物车管理 |
| 订单 | `/api/orders/*` | 订单创建、状态流转 |
| 评价 | `/api/reviews/*` | 评价提交和查询 |
| 用户 | `/api/user/*` | 个人信息、地址管理 |
