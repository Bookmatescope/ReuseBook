| 类型 | 地址 | 说明 |

## 2. 功能流程

### 2.1 首页（Landing）

1. 打开前端地址，可看到「书海拾贝」标语及 CTA 按钮。
2. 按钮包括：`立即注册`、`已有账号？登录`、`快速上传封面`、`发布二手书`。

### 2.2 注册

1. 点击「立即注册」进入 `/register`。
2. 填写邮箱、昵称、密码，提交后提示成功信息。
3. 后台返回用户 ID，可在浏览器 Console 查看网络响应。

### 2.3 登录

1. 访问 `/login`，输入邮箱与密码。
2. 成功后在页面底部展示 token 片段，便于复制。
3. 失败情况（密码错误）会显示中文错误提示。

### 2.4 上传封面

1. 从首页点击「快速上传封面」进入 `/upload`。
2. 选择分类（默认 `book-cover`），上传本地图片。
3. 页面显示图片预览与上传结果 URL，方便粘贴到后续书籍发布表单。

### 2.5 发布二手书

1. 从首页点击「发布二手书」进入 `/publish`。
2. 输入 ISBN 后点击「查询」可自动填充书名与作者。
3. 填写价格、品相、描述，可上传封面图片。
4. 提交后调用 `POST /api/books` 创建书籍记录。

### 2.6 浏览书籍列表

1. 访问 `/books` 可查看全部二手书。
2. 使用搜索框可按书名、作者、ISBN 模糊搜索。
3. 分页显示每页 8 本书籍，支持翻页。
4. 点击单本书籍卡片进入详情页，查看完整信息。

### 2.7 书籍详情

1. 在 `/books/{id}` 查看书籍的完整信息。
2. 显示封面、书名、作者、ISBN、价格、品相、描述等。
3. 可点击「加入购物车」按钮添加至购物车。

### 2.8 购物车

1. 在书籍详情页点击「加入购物车」。
2. 访问 `/cart`（待前端实现）查看已添加商品。
3. 可修改商品数量或删除商品。
4. 显示商品小计与总金额。

### 2.9 个人中心

1. 登录后访问 `/profile`（待前端实现）。
2. 可查看和修改个人昵称。
3. 管理收货地址：添加、编辑、删除、设为默认。

### 2.10 订单

1. 在购物车页面点击「结算」创建订单。
2. 选择收货地址，确认订单信息。
3. 订单创建后可在「我的订单」查看订单状态。

## 3. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 上传报错「图片大小不能超过 5MB」 | 压缩图片或更换更小尺寸 |
| 登录失败「邮箱或密码错误」 | 核对是否已注册，或在控制台检查请求参数 |
| Profile 接口返回 401 | 确认请求头中 `Bearer token` 是否携带 |
| Token 过期 | 调用 `/api/auth/refresh` 刷新令牌 |
| 添加购物车提示「书籍不存在」 | 确认书籍 ID 正确且已创建 |
| 搜索无结果 | 尝试更短的关键字或检查拼写 |
| 订单创建失败 | 确认已选择收货地址且购物车不为空 |
