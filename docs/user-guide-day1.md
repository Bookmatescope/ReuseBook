# 用户手册（Alpha Day 1 初稿）

> 负责人：陈东楷

本手册面向测试同学及业务干系人，说明目前可体验的功能及操作流程。后续页面截图待 UI 提供后补齐，先以占位描述。

## 1. 访问入口

| 类型 | 地址 | 说明 |
|------|------|------|
| 前端预览 | `http://localhost:5173` | Vite Dev Server，运行 `npm run dev` 后访问 |
| 后端接口 | `http://localhost:8081` | Spring Boot，运行 `mvn spring-boot:run` |

## 2. 功能流程

### 2.1 首页（Landing）
1. 打开前端地址，可看到「书海拾贝」标语及 CTA。
2. 按钮：`立即注册`、`已有账号？登录`、`快速上传封面`。
3. **截图占位**：`/docs/images/landing.png`（待补充）。

### 2.2 注册
1. 点击「立即注册」进入 `/register`。
2. 填写邮箱、昵称、密码，提交后提示成功信息。
3. 后台返回用户 ID，可在浏览器 Console 查看网络响应。

### 2.3 登录
1. 访问 `/login`，输入邮箱与密码。
2. 成功后在页面底部展示 token 片段，便于复制。
3. 失败情况（密码错误）会显示中文错误提示。

### 2.4 上传封面
1. 从首页点击「快速上传封面」进入 `/upload`。
2. 选择分类（默认 `book-cover`），上传本地图片。
3. 页面显示图片预览与上传结果 URL，方便粘贴到后续书籍发布表单。

## 3. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 上传报错「图片大小不能超过 5MB」 | 压缩图片或更换更小尺寸 |
| 登录失败「邮箱或密码错误」 | 核对是否已注册，或在控制台检查请求参数 |
| Profile 接口返回 401 | 确认请求头中 `Bearer token` 是否携带 |
